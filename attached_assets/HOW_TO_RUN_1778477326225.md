# How to Run the Wheel Screener — Step by Step

A beginner-friendly walkthrough for macOS. The whole thing should take
about 5 minutes the first time, and about 5 seconds every time after.

## 1. Check that Python is installed

Open the **Terminal** app (press `Cmd + Space`, type "Terminal", hit
Enter). Then run:

```bash
python3 --version
```

You want **Python 3.9 or newer**. If you see something like
`Python 3.11.5`, you're good. If it says "command not found," install
Python from <https://www.python.org/downloads/macos/> or via Homebrew:

```bash
brew install python
```

## 2. Navigate to the project folder

The project lives in `~/Desktop/Wheel Trader/wheel_screener`. The space
in "Wheel Trader" matters — wrap the path in quotes:

```bash
cd "~/Desktop/Wheel Trader/wheel_screener"
```

To confirm you're in the right place, list the files:

```bash
ls
```

You should see `README.md`, `screener.py`, `config.py`, `data.py`,
`greeks.py`, and `requirements.txt`.

## 3. Create a virtual environment (one-time setup)

A virtual environment keeps this project's Python packages separate
from everything else on your computer. You only have to do this once.

```bash
python3 -m venv .venv
```

That creates a hidden `.venv` folder inside `wheel_screener`. Activate
it:

```bash
source .venv/bin/activate
```

You'll know it worked when your terminal prompt gets a `(.venv)` prefix.
From now on, any `pip install` you run only affects this project.

> **Note:** Every time you open a new Terminal window to run the
> screener, you'll need to `cd` into the folder and `source .venv/bin/activate`
> again. Step 4 (installing dependencies) you only ever do once.

## 4. Install dependencies (one-time setup)

With the virtual environment active, run:

```bash
pip install -r requirements.txt
```

This installs `yfinance`, `pandas`, `numpy`, `scipy`, and `rich`. Takes
about 30 seconds. You'll see a wall of `Successfully installed ...` at
the end.

## 5. Run the screener

The simplest invocation — uses the default watchlist (30 popular
tickers) and default parameters (DTE 25–50, target delta 0.25):

```bash
python screener.py
```

You'll see each ticker scroll by as it's scanned, then a colored table
of the top candidates at the bottom.

> **First run is slowest.** The screener pulls option chains from
> Yahoo Finance for every ticker × every qualifying expiration. Expect
> 30–90 seconds for 30 tickers on the first run. After that, results
> are cached for 15 minutes, so re-running is instant.

## 6. Read the output

The table has these columns:

| Column          | What it means |
| --------------- | --- |
| **Ticker**      | The stock symbol. |
| **Spot**        | Current stock price. |
| **Expiry**      | The option's expiration date. |
| **DTE**         | Days to expiration. |
| **Strike**      | The put strike — where you'd be assigned the stock. |
| **Δ**           | Estimated absolute delta. Roughly: probability of assignment. |
| **Bid**         | What the market will pay per share for the put (× 100 = per contract). |
| **IV**          | Implied volatility of that specific contract. |
| **IV rank**     | Where current vol sits in its 1-year range (0 = low, 100 = high). Higher = richer premium. Approximated from realized vol — see README. |
| **Premium/ctr** | Total premium per contract = bid × 100. |
| **Collat/ctr**  | Cash needed to back one contract = strike × 100. |
| **Static %**    | Premium ÷ collateral. The return if the put expires worthless. |
| **Annualized %**| Static % × (365 / DTE). Compare trades on equal footing. |
| **Breakeven**   | Strike − premium. If the stock closes below this at expiry, you're underwater on the trade. |
| **% OTM**       | How far the strike is below the current stock price. |

The table is sorted by **annualized %** by default. But don't just chase
the highest number — high annualized yield usually means high IV, which
usually means the market expects something to happen (earnings,
litigation, macro news). Read the section below on sanity checks.

## 7. Common variations

**Screen only a few tickers** — useful when you want a quick check on
a specific watchlist:

```bash
python screener.py --tickers AAPL MSFT NVDA F SOFI
```

**Change the target delta** — 0.30 is more aggressive (more premium,
higher assignment risk); 0.15 is more conservative:

```bash
python screener.py --target-delta 0.30
```

**Change the DTE window** — go shorter for faster turnover, longer for
more premium:

```bash
python screener.py --min-dte 14 --max-dte 28
```

**Show more candidates**:

```bash
python screener.py --top-n 30
```

**Combine flags**:

```bash
python screener.py --tickers AAPL MSFT NVDA --target-delta 0.30 --min-dte 30 --max-dte 45 --top-n 15
```

**Save results to a spreadsheet**:

```bash
python screener.py --csv ~/Desktop/wheel_candidates.csv
```

That writes a CSV you can open in Excel, Numbers, or Google Sheets.

## 8. Customize the default watchlist permanently

If you keep typing the same `--tickers` list, edit `config.py` and
change the `tickers` list at the top. Use a text editor like
TextEdit, VS Code, or right inside Terminal:

```bash
open -a TextEdit config.py
```

The list looks like this:

```python
tickers: List[str] = field(default_factory=lambda: [
    "AAPL", "MSFT", "GOOGL", ...
])
```

Add or remove symbols, save the file, and next time you run
`python screener.py` (with no flags) it'll use your new defaults.

You can also change the other defaults in `config.py` — target delta,
DTE window, liquidity floors, etc. Comments above each field explain
what they do.

## 9. Sanity checks before acting on a candidate

The screener is a starting point, not a buy signal. Before selling any
put, ask yourself:

- **Would I be happy owning 100 shares at the strike price?** If no,
  don't sell the put.
- **Is there an earnings report inside the DTE window?** Check the
  company's investor relations page or any free earnings calendar.
  Earnings can blow up wheel trades.
- **Is the bid–ask spread reasonable?** If the spread is wider than
  ~10–15% of the bid, fill quality will suffer.
- **What does a 20% drop in the underlying do to the trade?** If you
  can't stomach being assigned at the strike during a sharp drop, this
  isn't the right ticker.
- **Is the company in the middle of something unusual?** Lawsuits, FDA
  decisions, takeover rumors, etc. all inflate IV for a reason.

## 10. Troubleshooting

**"command not found: python3"** — install Python from
<https://www.python.org/downloads/macos/>.

**"No module named 'yfinance'"** — your virtual environment isn't
active. Run `source .venv/bin/activate` first, or you forgot
`pip install -r requirements.txt`.

**"Failed to fetch spot for X"** — Yahoo Finance temporarily blocked
or rate-limited you. Wait a minute, or run with a smaller `--tickers`
list. Yahoo throttles aggressive scraping.

**Empty results table** — your filters were too strict. Try widening
the delta band in `config.py` (e.g., `min_delta = 0.10`,
`max_delta = 0.40`) or relaxing the liquidity floor
(`min_open_interest = 50`).

**Want to start fresh** — delete the cache: `rm -rf .cache`.

**Want to leave the virtual environment** — type `deactivate`. To get
back in next time: `cd ~/Desktop/Wheel\ Trader/wheel_screener && source .venv/bin/activate`.

## 11. A quick recipe for daily use

After the one-time setup (steps 1–4), running the screener every
morning looks like this:

```bash
cd "~/Desktop/Wheel Trader/wheel_screener"
source .venv/bin/activate
python screener.py --csv ~/Desktop/today_candidates.csv
```

That's it. Three lines. Review the table, open the CSV in your
spreadsheet of choice, and decide what (if anything) to act on.
