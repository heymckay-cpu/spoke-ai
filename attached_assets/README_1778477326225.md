# Wheel Screener — Starter Project

A small, self-contained Python tool that pulls option chains and finds
short-put candidates suitable for the wheel strategy. Uses free data
(yfinance) so you can start with zero API keys.

## What it does

For every ticker on your watchlist, it:

1. Pulls the current spot price and all available expirations.
2. Filters expirations to a target DTE window (default 25–50 days).
3. For each qualifying expiration, computes Black–Scholes delta for every
   put using the contract's implied vol from yfinance.
4. Picks the strike whose delta is closest to your target (default 0.25),
   inside a configurable band.
5. Scores the trade — premium, collateral, static return, annualized
   return, breakeven, distance OTM, an approximate IV rank.
6. Ranks all candidates by annualized yield and prints a table.

Results can be exported to CSV.

## Setup

```bash
cd wheel_screener
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Run

Use the default watchlist:
```bash
python screener.py
```

Override the watchlist on the command line:
```bash
python screener.py --tickers AAPL MSFT NVDA F SOFI
```

Tweak the screen:
```bash
python screener.py --target-delta 0.30 --min-dte 30 --max-dte 45 --top-n 25
```

Save results:
```bash
python screener.py --csv candidates.csv
```

## Customize

`config.py` holds the defaults — watchlist, DTE window, delta band,
liquidity floors, cache TTL. Edit there for persistent changes.

## What's approximated (and how to upgrade)

- **IV rank** uses 30-day realized (historical) vol as a proxy because
  yfinance doesn't expose true IV history. For real IV rank, swap
  `MarketData.get_iv_history_proxy` for a paid feed (Polygon options,
  ThetaData, or Tradier).
- **Delta** is computed from Black–Scholes using yfinance's implied vol.
  This is accurate enough for screening but won't exactly match what
  your broker shows. For broker-grade greeks, switch the data layer to
  Tradier's sandbox — it provides delta/gamma/theta/vega directly.
- **Quotes are delayed** (15 min) on yfinance. Fine for end-of-day
  decisions, not for live execution. Alpaca's free IEX feed or Tradier
  live are the easy next steps.
